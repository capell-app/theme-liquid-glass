# Theme Liquid Glass

<!-- prettier-ignore-start -->

Cards, figures and a floating row of shortcut links sit on frosted, see-through panels, and the page behind them shows through as a soft blur. You pick one of three looks. Clarity is teal and orange on a pale mint page. Prism is cyan and pink on pale blue, with larger headings and more room around things. Graphite is slate and amber on near-black.

Six of the theme's eight extra blocks, the ready-made sections you place on a page, use those panels. They include a call to action and a showcase of cards with images. A strip of figures counts up once.

Editors fill in each block's wording in an editing form in the widget editor. Until the wording is filled in, four of them show built-in sample headings. The footer shows the site name and a copyright line built from the site title and the year. Sections shared from Foundation do not get the blur. The theme needs the Foundation theme and Layout Builder, the page builder, installed.

On a device set to dark, the header and the panels in the eight blocks turn dark in all three looks. Before you apply the theme to the live site, you can preview it privately on your own pages.

## What this theme gives you

A modern glass look with translucent panels, crisp type, and warm accent buttons. Three presets cover bright product launches, editorial glass pages, and darker graphite surfaces.

## How to use it

1. Open the theme-management entry for **Theme Liquid Glass**, note the site's current theme, and select only the site you intend to review.
2. Choose **Preview Theme Liquid Glass** to view this theme privately on that site's existing content without changing its selected theme. Check available page areas, sections and the mobile layout; create a page first if there is nothing to preview.
3. When ready, choose **Apply Theme Liquid Glass** for that site. This changes its public design immediately, including already-published pages.
4. Use the shared Theme Studio editor to choose an available preset and adjust the standard theme controls.
5. Build the page with the theme's Layout Builder sections.
6. Review the saved page on desktop and mobile, including keyboard navigation.

To recover the previous design, reopen the previous theme's management entry, select the same site and choose its **Apply** button. This restores the theme selection; it does not undo content or shared Theme Studio settings. Saving those settings can affect public pages using that theme, so do not treat settings edits as private preview changes.

## What it adds

- Translucent glass sections and polished standard layouts.
- Three presets that restyle the whole site with no code.
- Portable demo content to start from.

## Good to know

- Built on **Foundation Theme** - install that first.
- Private theme preview keeps the current site theme selected until you choose **Apply**.

## Try fictional demo content safely

Use private theme Preview for existing content. Ask a developer to follow [safe demo setup](../../theme-foundation/docs/demo-setup.md) in a disposable local site when you want fictional sample pages instead.

A scoped demo run writes sample pages, widgets and demo layouts, including on repeats, and can adopt the site recovery page. An unscoped run refuses existing sites; a scoped run preserves site configuration unless the developer deliberately chooses the documented overwrite option. Review the target, languages and domains together before setup.
